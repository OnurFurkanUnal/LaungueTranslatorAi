# 🌍 Turkish ↔ English AI Translator

An AI-powered machine translation application for translating between **Turkish** and **English**. This project demonstrates a custom neural machine translation model capable of producing natural translations for everyday text and conversations.

## ✨ Features

* Turkish → English translation
* English → Turkish translation
* Local inference
* 🖥️ Simple desktop application
* 💻 Available for both Windows and Linux

## 🚀 Project Note

This translator is a **demonstration prototype** created to showcase the underlying machine translation system.

The current model is medium-sized and was primarily trained on movie and TV subtitle datasets. While these datasets provide a large amount of bilingual text, they often contain inconsistencies, informal language, simplified expressions, and translation errors. Subtitle translations are frequently adapted for readability or timing instead of being literal translations, introducing additional noise into the training data.

As a result, the model generally performs well on simple conversational sentences but may produce inconsistent translations for longer, more complex, or context-dependent text. At the same time, it can also generate surprisingly accurate translations for certain challenging inputs.

The primary objective of this project was to validate the architecture and demonstrate a working proof of concept. With access to professionally curated, high-quality parallel corpora, the same approach could be trained to achieve substantially higher translation quality and serve as a production-ready solution.

## ⚠️ Limitations

* Translation quality may vary depending on sentence complexity.
* Idioms, domain-specific terminology, and long contextual passages may not always be translated accurately.
* The model is intended as a research and demonstration project rather than a commercial translation service.
